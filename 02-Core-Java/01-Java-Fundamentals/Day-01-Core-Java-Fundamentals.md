A. Core Java Fundamentals – Interview Answers
These answers are framed for your 5+ years of QA Automation experience. Speak naturally in the interview. Each answer is designed to be concise, technically correct and suitable for a senior automation engineer.
1. What is Java? What are its main features?
Java is a high-level, object-oriented and platform-independent programming language. It is widely used for developing web applications, enterprise applications and automation frameworks. Its main features are platform independence, object-oriented programming, robustness, security, multithreading, portability and automatic memory management. In automation testing, I use Java with Selenium WebDriver to develop reusable automation scripts and frameworks.
2. Explain JDK, JRE and JVM.
JVM stands for Java Virtual Machine, which is responsible for executing Java bytecode. JRE stands for Java Runtime Environment, which provides the JVM and the libraries required to run Java applications. JDK stands for Java Development Kit, which includes the JRE along with development tools like the Java compiler. In simple terms, JDK is used to develop and run Java applications, whereas JRE is used to run them and JVM executes the bytecode.
3. How does Java achieve platform independence?
Java achieves platform independence through bytecode. When we compile a Java program, the compiler converts the source code into bytecode instead of generating machine code for a specific operating system. This bytecode can run on any operating system that has a compatible JVM. That's why Java follows the principle of Write Once, Run Anywhere.
4. What is bytecode?
Bytecode is the intermediate code generated by the Java compiler after compiling a Java source file. It is stored in a .class file and is not directly dependent on any operating system. The JVM reads this bytecode and converts it into machine-specific instructions for execution using interpretation and Just-In-Time compilation.
5. Explain the Java compilation and execution process.
First, we write Java source code in a .java file. The Java compiler, which is javac, compiles the source code and generates bytecode in a .class file. During execution, the JVM loads the class using the ClassLoader, verifies the bytecode and executes it through the execution engine. The execution engine uses an interpreter and JIT compiler to execute the instructions efficiently. Finally, the JVM manages memory and garbage collection during execution.
6. What are primitive and non-primitive data types?
Java data types are divided into two categories: primitive and non-primitive. Primitive data types store simple values directly and include byte, short, int, long, float, double, char and boolean. Non-primitive data types include String, arrays, classes and interfaces. They are used to represent objects and more complex data structures. For example, I use String to store test data and arrays or collections to manage multiple test values in automation.
7. What is the difference between local, instance and static variables?
Local variables are declared inside a method, constructor or block, and their scope is limited to that particular block. Instance variables are declared inside a class but outside methods, and every object gets its own copy. Static variables are declared using the static keyword and are shared among all objects of that class. In automation frameworks, instance variables are useful for maintaining object-specific data, whereas static variables can be used for shared class-level information when appropriate.
8. What are the default values of instance variables?
In Java, instance variables receive default values automatically when an object is created. Numeric types get zero, boolean gets false, char gets the null character '\u0000', and reference variables get null. For example, an int variable gets 0 and a String variable gets null if we don't initialize them. However, local variables do not receive default values, so we must initialize them before accessing them.
9. What is type casting? Explain widening and narrowing.
Type casting is the process of converting one data type into another. There are two types: widening and narrowing. Widening means converting a smaller data type into a larger compatible data type, such as int to long, and it happens automatically. Narrowing means converting a larger data type into a smaller data type, such as double to int, and it requires explicit casting. Narrowing may result in data loss.
10. What is the difference between implicit and explicit casting?
Implicit casting is the automatic conversion performed by Java when converting a smaller compatible data type into a larger data type. For example, int to double. Explicit casting is when we manually convert a larger data type into a smaller data type using the casting operator. For example, converting double to int using (int). Explicit casting can cause loss of precision or data.
11. What are operators in Java?
Operators are special symbols used to perform operations on variables and values. Java provides different types of operators, such as arithmetic, relational, logical, assignment, unary, bitwise, shift and ternary operators. For example, I use relational and logical operators in automation code to validate conditions and make decisions. Arithmetic operators are used for calculations, while assignment operators are used to assign values.
12. What is the difference between == and equals()?
The == operator compares primitive values directly, but when used with objects, it compares their references, meaning whether they point to the same object. The equals() method is used to compare object contents when the class provides an appropriate implementation. For example, when comparing two String objects, == checks references, whereas equals() checks their actual content. In automation testing, I generally use equals() to validate expected and actual String values.
13. What is the difference between break, continue and return?
The break statement terminates the nearest loop or switch statement completely. The continue statement skips the current iteration and moves to the next iteration of the loop. The return statement exits from the current method and can optionally return a value. In automation programming, I use these statements depending on whether I need to stop execution, skip an iteration or return a result from a reusable method.
14. What is the difference between final, finally and finalize()?
The final keyword is used to restrict modification. A final variable cannot be reassigned, a final method cannot be overridden and a final class cannot be inherited. The finally block is used with exception handling and generally executes whether an exception occurs or not. The finalize() method was historically associated with garbage collection before an object was reclaimed, but it is deprecated for removal in modern Java and should not be used for resource cleanup. I prefer try-with-resources for resource management.
15. Is Java pass-by-value or pass-by-reference?
Java is always pass-by-value. When we pass a primitive variable to a method, a copy of its value is passed. When we pass an object, a copy of the reference is passed to the method. Through that copied reference, we can modify the object's internal state, but reassigning the reference inside the method will not change the original reference outside the method. So Java does not support pass-by-reference.
16. Can we overload the main method?
Yes, we can overload the main method in Java by creating multiple main methods with different parameter lists. However, JVM execution starts only from the standard public static void main(String[] args) method. If we want to execute an overloaded main method, we need to call it explicitly from the standard main method. Method overloading is an example of compile-time polymorphism.
17. Can the main method be overridden?
No, the static main method cannot be overridden because static methods belong to the class rather than an individual object. However, if a child class declares a static main method with the same signature as the parent class, it is called method hiding, not method overriding. JVM executes the main method of the class specified during program execution.
18. What is the difference between static and non-static methods?
Static methods belong to the class, so we can call them directly using the class name without creating an object. Non-static methods belong to objects, so we need to create an object to access them. Static methods can directly access only static members, whereas non-static methods can access both static and non-static members. In automation frameworks, I use static methods for stateless utility operations and instance methods for object-specific operations.
19. What is a static block?
A static block is a block of code declared using the static keyword inside a class. It executes automatically when the class is initialized, generally before the main method executes. It is mainly used to initialize static variables or perform one-time class-level initialization. A class can contain multiple static blocks, and they execute in the order in which they are declared.
20. Can a static method access a non-static variable directly?
No, a static method cannot directly access a non-static variable because static methods belong to the class, whereas non-static variables belong to individual objects. However, we can access a non-static variable inside a static method by creating an object of that class and accessing the variable through that object. This is because an instance variable requires an object reference.
